# Machine learning evaluation

This report is generated by `EvaluationRunner`. Do not edit it by hand; run the command at the bottom.

**The data is synthetic.** It was produced by `scripts/generate_synthetic_data.py`, so the results show that the method works and is evaluated correctly. They do not show how well it would work on real students.

## Question

Using what is known about a student at the end of one term, can we predict whether the student's math score in the **next** term will be below 60? The result is meant to help a researcher decide where to look first. It is not a basis for decisions about individual students.

## Setup

- **Source file:** `synthetic_education_messy.csv`, cleaned by the import validator first (19217 accepted rows).
- **Examples:** 15878 pairs of consecutive terms. Features come from the current term and the one before it. The label comes only from the next term.
- **Split by student, not by row:** 60 percent train, 20 percent validation, 20 percent test. All rows of a student stay in one part, so the model is never tested on a student it has seen.

| Part | Students | Examples | Share below the cut next term |
|---|---:|---:|---:|
| Train | 1761 | 9504 | 51.8% |
| Validation | 600 | 3249 | 49.2% |
| Test | 587 | 3125 | 51.4% |

- **Preprocessing:** missing values are filled with the training mean and flagged with a missing indicator. Standardization is fitted on the training part only.
- **Model:** L2 regularized logistic regression written from scratch (Newton's method). The penalty was chosen on the validation part by log loss: lambda = 1.0 for the history only model and 1.0 for the other.
- **Decision threshold:** chosen on the validation part to maximize F1, then applied unchanged to the test part.
- **The test part was used once,** after every choice above was fixed.
- **Uncertainty:** 95 percent intervals come from 1000 bootstrap resamples of whole students in the test part.

Compare the mean predicted rate with the observed rate inside each group: if they match, the predicted probabilities are about equally well calibrated for every group. Recall and the share flagged differ partly because the groups have different base rates, and a single threshold flags more students in the group where the outcome is more common.

## Sanity check: shuffled labels

The same pipeline was trained on training labels that were shuffled at random, 20 times, and tested on the real test labels. With nothing to learn, the average AUC should be about 0.5. Single runs can land well above or below 0.5. AUC ignores the size of the weights, so even tiny random weights give a direction that can line up with, or against, the real signal, because the test features are strongly related to the real labels. What matters is that the average is near 0.5 and that no run comes close to the real model.

Test AUC with shuffled training labels: mean 0.494, range 0.239 to 0.688.

## Limitations

- **Synthetic data.** Scores in the generator are a student level ability plus noise, so next term math is largely a continuation of this term. High numbers here reflect that design. Real data is messier and the same method would need to be re evaluated.
- **Random split by student, not by time.** A forecasting study should also hold out the latest terms to check for drift. That is not done here.
- **One arbitrary label.** The cut of 60 is a choice. Other cuts, or predicting the score itself, may answer different questions.
- **A simple model.** Logistic regression is linear. Nonlinear models were not compared.
- **Intervals reflect resampling of test students only.** They do not include the effect of a different random split.
- **Fairness.** Using economic status or English learner status in a risk model can reproduce existing disparities. The model with these attributes is reported only for comparison.
- **Use.** This is for research exploration. It must not be the only basis for any decision about a student.
